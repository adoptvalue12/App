# TalkSnap Kids — Starter

Prototype web simple inspiré de Snapchat pour démarrer vite.

## Ouvrir
Double-clique `index.html` ou lance un petit serveur local.

## Fonctionnalités
- Création / connexion simulée
- Code ami unique
- Feed avec posts / reels
- Stories
- Messages
- Profil
- Paramètres
- Multilingue FR / EN / ES

## Notes
C'est un prototype frontend local.
On pourra ensuite le séparer en vrai projet avec backend, base de données et application mobile.
